## 🚀 Overview

PingMe is a full-stack real-time chat application designed for fast, secure, and seamless communication.

It provides instant messaging, authentication, media sharing, online presence, and AI-powered features to create a modern messaging experience.

This project is being built as a production-ready application following scalable software architecture and best development practices.

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/Aqueebkhn/PingMe.git
```

Go inside the project

```bash
cd PingMe
```

### Install Client

```bash
cd client
npm install
```

### Install Server

```bash
cd ../server
npm install
```

---

# ▶️ Run Locally

### Start Backend

```bash
npm run dev
```

### Start Frontend

```bash
npm run dev
```

---

# 🌍 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret_key

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=
```
